# 《别砸我的蛋》封面页 · 设计说明

> 阶段：仅 **封面 + 页面交互**，无战斗/存档逻辑。  
> 预览入口：`index.html`（封面 → 点按开始 → 主页占位）。

---

## 1. 风格定调（3D）

**一句话：** 轻卡通厚描边 **3D 展台封面** —— 像高级扭蛋机/潮玩展示柜，不是写实 CG，也不是扁平 Banner。

| 维度 | 定稿 |
|------|------|
| 机位 | **略仰视**，蛋在画面中上部，底座/光柱托住 |
| 造型 | Q 弹圆润；厚描边；大体块小细节 |
| 材质 | 蛋壳奶油高光、底座木/金属、环境暖金 rim light |
| 景深 | **前 / 中 / 后** 三层可动，形成 3D 纵深 |
| 色调 | 外壳深暖棕 `#3A2416` → 金 `#FFC53D` 主光；蛋高光 `#FFF6E8` |
| 动效 | 慢速漂浮 + 光斑缓转 + 金屑上浮；开始时冲击反馈 |
| 不要 | 写实人手砸蛋、恐怖裂缝阴间打光、UI 字烧进图里 |

### 给素材的 3D 图层建议（你出图时可按层切）

| 层 | 内容 | 透明底 |
|----|------|--------|
| L3 后景 | 舞台墙/光柱/远景道具虚影 | 可整图 |
| L2 中景 | **大金蛋 + 底座**（封面主角） | **要** |
| L1 前景 | 近景尘埃/碎片/柔光 | 要 |
| L0 字 | 标题可后期用引擎字，也可单独 3D 字图 | 要 |

单图版也可以：一张完整 3D 封面插画（≥1024×1536），代码仍叠光效/粒子；能出分层则视差更真。

## 2. 封面页内容清单（必有 / 可选）

### 必有（P0）

| # | 元素 | 说明 |
|---|------|------|
| 1 | **游戏标题** | 《别砸我的蛋》；厚描边/立体字；上架名一致 |
| 2 | **主视觉大金蛋** | 3D 展台中心；这是封面唯一角色焦点 |
| 3 | **点按开始 / 进入游戏** | 主 CTA；也可整屏点按 |
| 4 | **底座或光柱** | 托住蛋，强化 3D |
| 5 | **加载态** | 资源未就绪时进度条或「加载中」 |
| 6 | **版本号** | 角落小字，如 `v0.1.0` |

### 可选（P1，上架/完整版）

| # | 元素 | 说明 |
|---|------|------|
| 7 | 一句副标 | 例：「砸蛋攒炮台 · 守住大金蛋」；可弱化 |
| 8 | 音效开关 | 角落 |
| 9 | TapTap / 账号登录 | 真机上架需要；预览可隐藏 |
| 10 | 健康游戏忠告 / 隐私 / 用户协议 | 合规角标，上架前补 |
| 11 | 厂商 logo | 开场 0.8–1.5s 后进封面，或角标 |

### 封面 **不要** 放

- 背包/图鉴/商店/任务  
- 金/券资源条（那是主页的事）  
- 复杂玩法教学  
- 局内 UI  

### 文案与状态

| 状态 | 表现 |
|------|------|
| 加载中 | 进度条 + 「加载中」；CTA 禁用 |
| 可进入 | CTA 高亮 + 蛋呼吸光 |
| 点按开始 | 蛋震一下 → 白闪/金光 → **进入主页** |
| 素材未投放 | CSS 占位蛋 + 标题仍显示；不挡交互 |

## 3. 封面 → 主页 交互（本阶段）

```
加载完成
  → 标题淡入
  → 金蛋自光中升起（或 scale + 发光）
  → 「点按开始」浮入
用户点「开始」或点蛋
  → 蛋 scale 0.94→1 + 轻震 + 光爆
  → 300–500ms 过场
  → 主页（红框结构占位，逻辑后置）
```

主页占位仅验证导航，不接数值。

## 5. 本阶段不做

数值、广告、存档、砸蛋逻辑、战斗逻辑。只保证：**封面观感 + 点按进入主页的交互**可演示。
